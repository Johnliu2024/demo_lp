Curriculum

8 周，从空白文件到上线网址

每周一个主题、一个练习、一个可交付成果，节奏适合下班后学习。

01

网站到底是怎么跑起来的

浏览器、服务器、域名、文件之间的关系；准备好你的编辑器和本地预览环境。

产出：能本地打开的页面
02

HTML：搭出页面的骨架

常用标签、语义化结构、链接与图片，写出一个结构清晰的个人介绍页。

产出：个人介绍页
03

CSS 基础：让页面好看起来

选择器、盒模型、文字与颜色、层叠规则，理解样式为什么生效或失效。

产出：带样式的介绍页
04

布局：Flexbox 与 Grid

用现代布局方式搭建导航、卡片列表和页脚，并适配手机屏幕。

产出：响应式首页
05

设计令牌与主题系统

用 CSS 变量统一颜色、间距和圆角，实现一键切换的深色模式。

产出：可换肤的主题
06

JavaScript 入门：加入交互

变量、函数、事件与 DOM，做出移动端菜单和主题切换按钮。

产出：可交互的导航
07

组织多页面与复用组件

拆分 CSS 文件、统一命名规范，把首页、关于页、联系页串成一个完整站点。

产出：多页小网站
08

部署上线与作品整理

用静态托管服务发布网站，绑定自己的链接，并整理成可以展示的作品集。

产出：上线的真实网址

可以。课程默认你是零基础，从“网站是怎么运行的”讲起，不假设任何前置知识。每节课都配有完整演示和小练习，跟着做就能出成果。

一台能正常上网的 Windows 或 macOS 电脑即可。所有工具都是免费、跨平台的，课程里会带你一步步安装和配置，不需要额外付费购买软件。
